# ⚡ Arrow Escape

A polished, mobile-first arrow escape puzzle game built for smartphones and modern browsers, featuring online 1v1 duels, weekly tournaments with eligibility checks, customization shop, virtual coins economy with anti-farming rules, and persistent player profiles.

---

## 🎮 Game Overview

The player is presented with a rectangular board populated with directional arrows pointing in cardinal directions (Up, Down, Left, Right). 
- **Core Rule**: Tapping an arrow triggers a raycast check along its facing direction to the board boundary.
- **Escape**: If no other arrow blocks the path to the edge, the arrow flies off the board and disappears with smooth directional animations and procedural audio.
- **Obstacle Feedback**: If another arrow obstructs its path, the arrow shakes with an error buzz and remains in place.
- **Win Condition**: Clear all arrows from the board!

Every puzzle generated by the game is **100% mathematically verified to be solvable** through reverse-construction and forward-solver algorithms.

## 🚀 Game Features

### 1. Single-Player Campaign
- 4 difficulty tiers: **Easy (5x5)**, **Medium (6x6)**, **Hard (7x7)**, and **Expert (8x8)**.
- 60+ progressive campaign levels with star ratings and completion rewards.
- **Power-ups**:
  - 💡 **Hint**: Highlights an immediately escapable arrow.
  - ↩️ **Undo**: Restores the last escaped arrow to the board.
  - 🛡️ **Safe Arrow**: Reveals an arrow with a clear path.

### 2. Online 1v1 Mode
- Quick matchmaking with radar animation.
- Synchronized **3-2-1-GO!** countdown.
- Identical shared puzzle for both contenders.
- Real-time opponent progress tracker and live remaining-arrow counter.
- Dynamic Elo / MMR rating adjustments and coin rewards.

### 3. Weekly Tournament
- **Eligibility Requirement**: Players must complete at least **10 distinct qualifying levels** during the current tournament week to unlock entry.
- Shared weekly championship puzzle with millisecond-precision timing.
- **Fair Winner Selection**: Earliest verified completion time with deterministic tie-break hashes.
- **Regulatory Notice**: The planned ₹100 cash prize is disabled pending legal verification under Indian law and Google Play policies; players compete for virtual trophies, 1,000 coins, and leaderboard placement.

### 4. Customization Shop
- **Board Themes**: Classic Slate, Neon Cyber, Enchanted Forest, Ice World, Galaxy Cosmic, Golden Royalty.
- **Arrow Skins**: Standard, Royal Arrows, Legendary, Frost, Inferno, Thunder, Emerald.
- **Profile Avatars**: Arrow Pilot, Royal Prince, Cyber Ninja, Baby Dragon, Astronaut, Fox Gamer, Phantom.
- **Profile Frames**: Neon Frame, Royal Gold Frame, Mystic Frame, Diamond Frame.
- **Victory Effects**: Confetti Rain, Star Burst, Lightning Flash, Golden Shower.
- **Collection Bonus**: Unlocking the Royal Arrows, Royal Prince avatar, and Royal Gold frame unlocks the secret *Royal Collector* achievement badge!

### 5. Persistent Economy & Anti-Farming
- Virtual Coins are awarded for first-time level completions, daily challenges, achievements, and 1v1 duel victories.
- Replaying previously cleared levels does not grant duplicate coins, preventing farming exploits.

## 🛠️ Architecture & Tech Stack

- **Frontend**: Clean Vanilla ES6+ JavaScript, CSS3 with responsive viewport scaling, and HTML5.
- **Audio Engine**: Web Audio API synthesizer for zero-dependency procedural sound effects (whooshes, error buzzes, victory chords, coin chimes).
- **Storage**: LocalStorage state management with anti-farming ledger, tournament week calculation, and profile synchronization.
- **PWA Ready**: Works offline, touch-first responsive controls, and installable on Android / iOS home screens.
